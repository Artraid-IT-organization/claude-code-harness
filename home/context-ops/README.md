# Context Ops — экономика контекста Claude Code на VPS

> Актуально: 18.07.2026. Владелец: штаб (CDTO). Референс формата: AFM (`~/.claude/skills/afm/`).

**Зачем.** Недельный лимит подписки ($200) сжигался за 2 дня. Лимит жжёт не «ум» модели,
а объём контекста × частота запусков. Этот проект — постоянная методика, чтобы держать
расход под контролем и не повторять ресёрч каждый раз.

## Состав

| Файл | Что это |
|---|---|
| `METHOD.md` | **Методика**: 3 статьи расхода, нормативы-бюджеты, петля аудита, рычаги, чеклист запуска автоматики |
| `research/2026-07-18-best-practices.md` | Свод мировых практик с источниками (официальные доки + сообщество) |
| `audits/2026-07-18-audit.md` | Первый аудит VPS: цифры, диагноз, план решений |
| `audits/*-raw.md` | Сырые замеры скрипта (история) |
| `bin/ctx-audit.sh` | Скрипт повторного замера — вся фактура за один запуск |

## Как пользоваться

- Раз в неделю или при жалобе «жжём лимит»: сказать в чате **«проведи контекст-аудит»**
  (скилл `ctx-audit`) — замер → диагноз против нормативов → план.
- Перед запуском нового бота/крона — чеклист в конце `METHOD.md`.
- Сверка реального расхода — `/usage` в интерактивной сессии.
