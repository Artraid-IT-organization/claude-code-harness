## Гейт исполнителя

Если сессия запущена в каталоге проекта с СОБСТВЕННЫМ `CLAUDE.md` — ты исполнитель: работай по
проектной обвязке, штабные пункты ниже не читай (экономия контекста). Петля обучения и дисциплина
`agent.md` действуют всегда.

## По запросу

- `~/.claude/workspace/SERVICES.md` — снапшот сервера: systemd, docker, cron, порты, MCP.
  **Генерируется** `~/scripts/gen_services.py`, руками не править
- `~/reports/` — отчёты руководству: методика, генератор docx, архив; скилл `report`
- `~/context-ops/` — экономика контекста: методика, аудиты, свод практик
- `~/vault/` — задачи, проекты, решения, знания

## Экономика контекста

- Сессия = одна задача; между несвязанными — `/clear`; `/compact` вручную на 40–50%
- Ресёрч по коду и файлам — субагентом: в контекст возвращается вывод, а не файлы
- Автоматика зовёт `claude` ТОЛЬКО с явным `--model` по cost curve (чеклист — `~/context-ops/METHOD.md`)
- Раз в неделю или при жалобе на лимит: «проведи контекст-аудит» (скилл `ctx-audit`)

## Исходящие артефакты

Файл, уходящий человеку (руководству, коллеге, подрядчику, в мессенджер, почтой) — **по умолчанию
Word `.docx`**, не Markdown. `.md` только если попросили явно или это внутренний технический
документ. Данные и таблицы — `.xlsx`. Перед отправкой — проверка рендером: кириллица на месте,
символов замены нет.

## Долгие процессы — через раннер

Пачечная работа дольше ~5 минут или больше ~50 единиц (массовый разбор, синхронизация, выгрузка)
запускается **через `~/scripts/runjob.sh`**, не разовым скриптом. Он даёт: пропуск уже сделанного,
докрутку волнами до нулевого остатка, файл состояния с временем последнего успеха, живучесть после
обрыва сессии. Статус в чат — из `STATUS`-файла (`runjob.sh status <имя>`), а не подсчётом файлов
глазами: счётчик может стоять часами и выглядеть как «идёт».

## Само-дисциплина

**Петля обучения** (`~/.claude/learning-loop/`, локально, персональные данные маскируются): на старте
сессии хук инъектирует «уроки прошлых сессий» — учитывай их перед нетривиальным действием. Детали по
задаче: `python3 ~/.claude/learning-loop/loop.py recall --task-kind <kind>`.

ЗАХВАТ УРОКА — когда владелец тебя поправил ИЛИ ты нашёл неочевидную ошибку, ловушку или красную зону:

```
python3 ~/.claude/learning-loop/loop.py record-trace --agent staff --task-kind <kind> \
  --domain-keys "<модуль/владелец>" --input "<что хотел>" --output "<что пошло не так>" \
  --outcome fail --error-class "<урок одной фразой>"
python3 ~/.claude/learning-loop/loop.py evaluate
python3 ~/.claude/learning-loop/loop.py distill
```

`evaluate` обязателен — без него `distill` не видит трейс.

**Дисциплина `agent.md`:** DoD любой правки кода = обновить релевантный `agent.md` подсистемы, если он
есть (плотно, указатель и неочевидное, без дублирования кода). Новый модуль или подсистема больше
~120 строк кода без `agent.md` → завести в моменте.
