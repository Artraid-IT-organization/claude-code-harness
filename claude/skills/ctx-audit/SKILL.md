# Контекст-аудит (Context Ops)

Канон: `~/context-ops/METHOD.md` (нормативы, рычаги), `~/context-ops/research/` (свод практик — ресёрч НЕ повторять).

1. Запусти `~/context-ops/bin/ctx-audit.sh` — raw-замер ляжет в `~/context-ops/audits/<дата>-raw.md`.
2. Прочитай `METHOD.md` и последний курированный аудит в `audits/` (образец формата).
3. Сравни замер с нормативами → диагноз (что 🔴/🟡) + дельта к прошлому аудиту.
4. План — из таблицы рычагов METHOD.md, сверху вниз, решениями («делаю X, потому что Y»), не опциями.
5. Запиши курированный аудит `audits/<дата>-audit.md` (диагноз + план + контроль через 7 дней), сводку — в чат бизнес-языком.

Правки конституционных файлов владельца (SOUL/USER/PROTOCOLS/принципы) — только после его ок.
